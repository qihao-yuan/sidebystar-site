# 官网首页更新 · 2026-10-30

首页改为冷白、浅银和少量蓝色的产品展示，保留七系列正式命名、实际操作录像、产品手册与中英文入口。以 `3fd32ac` 为基础；没有覆盖另一分支内的产品目录草稿。

## 内容与维护

- `components/home/PremiumHome.tsx`：中英文首页、三个可操作的示例、场景切换和视频弹层。示例只操作当前页面数据，不连接客户家庭。
- `components/home/PremiumHome.module.css`：首页排版和响应式样式；包含入场、滚动和切换动效以及减少动态效果设置。
- `content/product-visuals.ts`：所有产品展示位置共用的图片来源，改为 V23 已批准的压缩图；历史软件录像路径保持原样。
- `public/home/premium/asset-manifest.json`：11 项所引用媒体的来源、摘要和设计／场景身份。直接复用既有 V23 文件，没有新增媒体副本。
- `components/nav/SiteNav.tsx` 与 `app/globals.css`：首页浅色导航和页脚；内部页面继续使用原有样式。

## 验证与交付边界

生产构建生成 87 个页面，包含类型与 Lint 检查。`browser-check.json` 记录中英文、手机与桌面、可操作示例、影片弹层和滚动变换的检查；`http-and-media-check.json` 记录 16 项页面及媒体访问结果。

动效使用现有 Framer Motion，未增加依赖；页面和图片在动画关闭时仍可浏览。影片均无音轨，点击后才加载播放器。短片是场景演绎，产品图片是设计效果图。

本轮为桌面浏览器及尺寸模拟验证，未验证实际 iPhone。未登录远程服务器或部署公网；沿用用户自行部署的安排。注册 Apple 开发者公司会员与原生 iPhone App 的签名发布由另一交付记录单独管理。
