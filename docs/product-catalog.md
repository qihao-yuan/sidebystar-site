# 循星硬件产品清单

> 内部规划稿。用于产品定义、设计评审和官网信息准备，不代表已量产、已认证或已开放销售。

## 1. 产品体系

循星硬件分为五类：

- **Compute**：运行 AIOS、保存现场状态并执行规则。
- **Sense**：采集空间、设备与照护事件。
- **Control**：提供实体操作、确认与呼叫入口。
- **Connect**：连接不同协议、网络与既有系统。
- **Act**：执行照明、窗帘、暖通和干接点控制。

产品状态使用以下标记：

- **已定义**：已有产品定位和网站规格，硬件配置仍以项目文件为准。
- **候选自研**：建议由循星定义外观、硬件、固件和生命周期，尚未完成量产确认。
- **生态选型**：优先采用经过验证的第三方认证产品，循星负责适配和交付。
- **路线图**：方向成立，但尚未进入正式产品定义。

## 2. 计算平台

### SBS-C01 · Home Box

- 类别：Compute
- 状态：已定义
- 场景：单户住宅、样板间、单一照护房间
- 计算基线：Raspberry Pi Compute Module 5 级
- 主要职责：
  - 本地设备接入与状态管理
  - 房间及家庭自动化规则
  - 基础本地推理
  - 事件与操作记录
- 配套产品：空间感知器、墙面场景面板、多协议接入网关
- 安装方式：桌面、壁柜或弱电箱托架
- 说明：外部接口集中在背面，不作为强电控制器使用。

### SBS-C02 · Community Gateway

- 对外名称：Community Kit
- 类别：Compute
- 状态：已定义
- 场景：长者公寓、社区照护中心、酒店与多房间项目
- 计算基线：NVIDIA Jetson Orin NX 级
- 主要职责：
  - 20–200 个户内或房间节点的分级管理
  - 多源事件融合与边缘推理
  - 告警、工单和角色权限
  - 站点内记录与同步
- 配套产品：空间感知器、离床感知器、床旁呼叫器、配电箱回路控制器
- 安装方式：设备间、楼层弱电柜或受控管理空间

### SBS-C03 · Enterprise Stack

- 类别：Compute
- 状态：已定义
- 场景：医院、大型照护机构和园区私有化部署
- 形态：19 英寸 2U 机架设备
- 计算基线：x86 服务器与项目选定 GPU
- 主要职责：
  - 多站点和多楼层管理
  - 院内模型与数据服务
  - 既有信息系统集成
  - 集中权限、审计和运维
- 配套产品：社区网关、多协议接入网关、配电箱回路控制器
- 安装方式：标准机柜
- 说明：GPU、存储、冗余和接口配置按项目确认，不在网站承诺固定型号。

## 3. 感知设备

### SBS-S01 · 空间感知器

- 类别：Sense
- 状态：候选自研
- 场景：住宅、照护房间、客房和公共空间
- 目标输入：
  - 人体存在与区域活动
  - 低位静止风险
  - 温度、湿度和照度
  - 可选环境噪声事件，不保存连续录音
- 推荐技术：毫米波、红外与环境传感器组合
- 安装方式：墙装或顶装
- 数据边界：输出结构化状态和事件，不默认输出图像或连续音频。
- 设计重点：安装后弱存在感；正面不得出现大面积标志和高亮指示灯。

### SBS-S02 · 离床感知器

- 类别：Sense
- 状态：生态选型
- 场景：养老机构、护理院和辅助病区
- 目标输入：
  - 在床、离床和回床状态
  - 超时未回床
  - 可选床旁活动状态
- 推荐形态：床垫下压力传感器或床架低压传感模块
- 接口：低压有线或受控无线连接
- 数据边界：不采集生理诊断数据，不作为医疗监护设备宣传。
- 选型要求：可清洁、可更换、抗误触发，并适配护理床结构。

### SBS-S03 · 门窗状态传感器

- 对外名称：门窗与状态传感器
- 类别：Sense
- 状态：生态选型
- 场景：入户门、房门、药柜、设备柜和窗户
- 目标输入：开合、长时间未关闭和防拆状态
- 接口：Matter、Thread、Zigbee 或低压干接点
- 说明：优先接入成熟认证设备，不建议为通用门磁单独开模。

## 4. 控制设备

### SBS-U01 · 墙面场景面板

- 类别：Control
- 状态：候选自研
- 场景：住宅入口、床旁、客房和护理站
- 目标能力：
  - 旋钮调节
  - 2–4 个可配置实体按键
  - 场景状态与故障提示
  - 高风险动作二次确认
- 安装方式：86 型底盒或低压壁装
- 交互原则：常用动作不依赖触摸屏；断网时保留基础控制。

### SBS-U02 · 床旁呼叫器
- 类别：Control
- 状态：生态选型
- 场景：养老机构、护理院和辅助病区
- 目标能力：
  - 单次按压呼叫
  - 呼叫已送达反馈
  - 护理员到场确认
  - 防误触与防拆
- 安装方式：床旁固定、拉绳或可拆手持
- 说明：涉及紧急呼叫可靠性时，优先选用成熟护理呼叫设备并保留原系统。

## 5. 连接设备

### SBS-N01 · 多协议接入网关

- 类别：Connect
- 状态：候选自研
- 场景：住宅、社区和机构设备接入
- 目标协议：
  - Matter / Thread
  - Zigbee
  - BLE
  - RS485 / Modbus
  - 可选 KNX、BACnet 或厂商私有协议
- 主要职责：
  - 设备发现、登记和能力映射
  - 本地状态同步
  - 指令下发和失败记录
- 安装方式：桌面、弱电箱或 DIN 导轨适配托架
- 说明：协议支持和设备兼容是两件事，最终兼容范围以型号与固件实测清单为准。

## 6. 执行设备

### SBS-A01 · 配电箱回路控制器
- 类别：Act
- 状态：生态选型，循星定义接口与外观规范
- 场景：照明、窗帘、风机盘管、阀门和通用干接点
- 目标能力：
  - 4/8 路低压输入
  - 4/8 路继电器或干接点输出
  - 手动旁路
  - 回路状态与故障反馈
- 安装方式：配电箱或楼控柜 DIN 导轨
- 安全边界：
  - 强电开关、调光和电机负载必须使用符合项目所在地认证要求的模块。
  - AIOS 不得绕过消防、应急照明和设备原有安全保护。
  - 控制器失联时应回到项目定义的安全状态。

### SBS-A02 · Lighting Interface

- 类别：Act / Connect
- 状态：路线图
- 场景：高端住宅、酒店和公共空间照明
- 目标接口：DALI-2、0–10V、可控硅调光或项目指定总线
- 主要职责：灯组映射、亮度与色温控制、执行结果反馈
- 说明：是否独立成品化，取决于配电箱回路控制器与第三方照明系统的覆盖范围。

## 7. 配套附件

附件不作为核心产品单独宣传，但必须进入交付清单：

- 设备电源与 PoE 分离器
- 短时后备电源或直流 UPS
- 墙装、桌面和 DIN 导轨安装件
- 弱电箱与机柜理线附件
- 传感器校准与安装定位工具
- 备用电源、连接线和替换件

## 8. 标准组合

### Residential Starter

- Home Box
- 1–3 个空间感知器
- 1 个墙面场景面板
- 1 个多协议接入网关
- 安装、设备登记和基础规则配置

### Care Room

- Community Gateway 或房间边缘节点
- 空间感知器
- 离床感知器
- 床旁呼叫器
- 路径照明或低压执行接口
- 告警、工单和角色权限配置

### Facility Deployment

- Enterprise Stack
- 每楼层 Community Gateway
- 空间感知器、离床感知器与床旁呼叫器
- 多协议接入网关与配电箱回路控制器
- 院内接口、权限、审计和运维交付

## 9. 官网发布条件

任何产品进入官网正式产品区前，至少应具备：

1. 已冻结的产品名称、型号和用途。
2. 可拍摄的工程样机或可信工业设计渲染。
3. 明确的自研、合作或第三方身份。
4. 可公开的尺寸、供电、接口和安装方式。
5. 已确认的认证状态，不得使用“认证中”代替认证结果。
6. 兼容设备与固件版本清单。
7. 安装、升级、回滚和售后责任人。
8. 不夸大医疗、安全和节能效果的公开文案。
